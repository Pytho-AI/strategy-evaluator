# Style guide: reference entry (doc_type `reference_entry`)

The regenerated reference product for one entity. <= 400 words. Directive paragraph scheme.

    1. Reference Entry: <entity canonical name> (aliases).
    a. Identification. Type, parent, location [src: ...].
    b. Attributes. One sentence per attribute with value and unit [src: ...].
    c. Assessment. Analytic judgments with one ICD 203 term each; confidence in a separate sentence.
    d. Sources. <source_id>: reliability X, credibility n.
    Acronyms used: ...

Follows `icd203.md` for likelihood and confidence and `cjcs_directive.md` for everything else.
