# Style guide: ICD 203 estimative language (assessments, reference entries)

Sources: ICD 203 (12 Jun 2023) as reproduced in CJCSM 3105.01C Fig. 19 (p. C-4) and Encl. C
§4.a(1), §4.c (p. C-4–C-5).

## Likelihood (1A.5)
Only the seven ICD 203 terms, lower case, in prose:

| term | band |
|---|---|
| almost no chance | 01–05% |
| very unlikely | 05–20% |
| unlikely | 20–45% |
| roughly even chance | 45–55% |
| likely | 55–80% |
| very likely | 80–95% |
| almost certain / almost certainly | 95–99% |

Pattern: `The <author> assesses that <proposition> is <term>` or
`It is <term> that <proposition>`. Never "probable", "may well", "might", "could", "possibly".
Never mix in the JRAM four-level vocabulary (see `jram_risk_statement.md`); an intelligence
product never says `"Likely" probability`, "risk level" or "trending up".

## Confidence (1A.6)
Only `low`, `moderate`, `high`, with the JRAM Encl. C §4.c meaning. Confidence is stated in a
separate sentence from any likelihood term:

    The theater J-2 assesses that Red will mobilize two brigades within thirty days [src: src_0031].
    Confidence in this judgment is moderate.

Never: "We assess with moderate confidence that Red is likely to ..." (invariant 12).

## Facts versus judgments
- A reported fact (`estimative = false`) carries no likelihood term; only confidence: "The battery
  holds twelve launchers [src: src_0007]. Confidence is high."
- An analytic judgment (`estimative = true`) carries exactly one likelihood term.

## Sourcing (1A.13)
Every asserted fact: `[src: src_xxxx]`. Final sources paragraph:
`n. Sources. src_0007: reliability B, credibility 2. src_0031: reliability C, credibility 3.`

## Realism perturbations that touch this guide
- `hedge_drift` (news and situation reports only, never assessments or reference entries): the
  document uses a non-ICD synonym ("probable"); truth stores the nearest ICD term and the surface
  term in `claims.likelihood_surface_term`.
- `mixed_scale`: exactly one T0 assessment deliberately mixes the two vocabularies; it is a
  negative example that `eval/style_check.py` must flag (code 13).
