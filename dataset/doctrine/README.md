# doctrine/

The five authoritative documents live in the repository root `doctrine/` directory (PDFs are
public releases and are not committed; copy them in with the names below). `EXTRACTS.md` in
this directory holds the verbatim scales, templates, and definitions the generator relies on,
each cited to document, enclosure/chapter, figure, and page, so a reviewer can check fidelity
without opening the PDFs.

| Short name | File (repo root `doctrine/`) | Document |
|---|---|---|
| JRAM | `CJCSM_3105_01C.pdf` | CJCSM 3105.01C, Joint Risk Analysis Methodology, 10 July 2026 |
| JP 5-0 | `18-F-1152_JP_5-0.pdf` | JP 5-0, Joint Planning, 1 December 2020 (FOIA release 18-F-1152) |
| JSPS | `CJCSI_3100_01F.pdf` | CJCSI 3100.01F, Joint Strategic Planning System, 29 January 2024 |
| JP 2-01 | `JP2_01.pdf` | JP 2-01, Joint and National Intelligence Support to Military Operations, 5 January 2012 |
| JP 3-60 | `JP_3-60.pdf` | JP 3-60, Joint Targeting, 20 September 2024 |

ICD 203, Analytic Standards (12 June 2023), is not in hand; its 7-level likelihood scale and
three confidence levels are applied as reproduced in JRAM Figure 19 and Enclosure C paragraph 4.c.

`SOURCES.sha256` records the digests of the PDFs the extracts were taken from.
